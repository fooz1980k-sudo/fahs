# افحص سيرتك مجاناً — أداة صمّم لي

## وش هي؟
صفحة ويب مجانية (ثابتة، بدون سيرفر) يرفع فيها الزائر سيرته الذاتية (PDF أو Word ‎.docx) ويطلع له فوراً:
- نسبة **جاهزية تقديرية** لأنظمة الفرز ATS من 100 (ضعيفة / متوسطة / جيدة / ممتازة).
- أهم 3 ملاحظات مع حل كل وحدة بسطر.
- قائمة الفحص الكاملة (✓ / ✗) بأوزان واضحة.
- لو لصق وصف وظيفة: نسبة التطابق، والكلمات الموجودة والناقصة.
- أزرار تودّي للمتجر: «خلّنا نصلحها لك»، «فحص احترافي»، كود FIRST15، وواتساب.

**الخصوصية:** الفحص كله داخل متصفح الزائر. السيرة ما تنرفع لأي مكان، وما فيه إحصائيات ولا تتبّع ولا أي اتصال خارجي غير خط Google Fonts. مكتبة قراءة PDF ‏(pdf.js 3.11.174) ومكتبة Word ‏(mammoth 1.8.0) محفوظة داخل المجلد `assets/vendor/`.

## خطوات النشر على GitHub Pages (للبوت أو يدوياً من المتصفح)
1. سجّل الدخول في GitHub بحساب **fooz1980k-sudo**.
2. افتح https://github.com/new
   - Repository name: `smmly-ats-check`
   - اختر **Public**.
   - لا تضيف README ولا .gitignore (خلّه فاضي).
   - اضغط **Create repository**.
3. في صفحة المستودع الجديد اضغط الرابط **uploading an existing file** (أو Add file ← Upload files).
4. فك ضغط `ats-check.zip` على الجهاز، ثم اسحب **محتويات** المجلد (مو المجلد نفسه) إلى صفحة الرفع:
   `index.html` و `.nojekyll` و `README-ar.md` ومجلد `assets` كامل.
   - تأكد إن `index.html` يطلع في جذر المستودع مباشرة، و`assets/...` بمساراتها.
   - ملاحظة: ملف `.nojekyll` مخفي في بعض الأجهزة؛ لو ما انرفع، سوّه من Add file ← Create new file باسم `.nojekyll` وخلّه فاضي.
5. اكتب رسالة مثل `first version` واضغط **Commit changes** (على الفرع `main`).
6. روح **Settings ← Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** والمجلد **/ (root)** ← **Save**.
7. انتظر دقيقة إلى ثلاث، وحدّث الصفحة. بيطلع الرابط:
   **https://fooz1980k-sudo.github.io/smmly-ats-check/**
8. افتح الرابط من الجوال، ارفع سيرة تجربة، وتأكد إن النتيجة تطلع وإن الأزرار تفتح صفحات المتجر.

## تعديلات سريعة
- روابط المتجر والكود والواتساب: داخل `index.html` في قسم `cta-card`.
- أوزان الفحص ونصوص الملاحظات: داخل `assets/app.js` في الدالة `analyze`.
- لو تغيّر رابط الموقع، عدّل روابط `og:url` و `og:image` و `canonical` في رأس `index.html`.

# أدوات صمّم لي المجانية

موقع ثابت (بدون سيرفر) على GitHub Pages: `https://fooz1980k-sudo.github.io/fahs/`
كل الأدوات تشتغل داخل متصفح الزائر. ما ينحفظ ولا ينرسل أي شي يكتبه أو يرفعه.
الشي الوحيد اللي يطلع من الصفحة: عدّاد GoatCounter مجهول (زيارات وأحداث بدون بيانات شخصية)، وخط Google Fonts.

## الصفحات
| المسار | الأداة |
|---|---|
| `/` | الصفحة الرئيسية (الأدوات الست + مين إحنا + رسالة منا لك + آراء العائلة) |
| `/fahs-cv/` | افحص سيرتك ATS |
| `/mukafaa/` | حاسبة مكافأة نهاية الخدمة (المادة 84 و85) |
| `/mawzoona/` | حاسبة النسبة الموزونة |
| `/rateb/` | حاسبة صافي الراتب بعد التأمينات |
| `/khitab/` | مولّد إيميل التقديم |
| `/dareeba/` | حاسبة ضريبة القيمة المضافة 15٪ |

## الملفات المشتركة
- `assets/style.css` التصميم لكل الصفحات.
- `assets/extras.js` التقييم بالنجوم، وصندوق «اكتب لنا رأيك»، وأزرار المشاركة، وعرض الآراء.
- `assets/growth.js` بطاقة نتيجتي (صورة 1080×1920) وتنبيهات التقديم على الواتساب.
- `assets/reviews.json` الآراء المعتمدة (فاضي `[]` لين تضيف آراء حقيقية بموافقة أصحابها).
- `assets/app.js` + `assets/vendor/` منطق فحص السيرة ومكتبتي pdf.js 3.11.174 و mammoth 1.8.0.
- `assets/og-*.jpg` صور المشاركة لكل صفحة.

## إضافة رأي معتمد
افتح `assets/reviews.json` في GitHub ← أيقونة القلم ← أضف الرأي ← Commit. **أضف بس الآراء اللي صاحبها كتب «موافق على النشر: نعم».**
```json
[
  {"name": "أبو فهد", "city": "جدة", "stars": 5, "text": "نص الرأي كما وصلكم", "tool": "cv", "date": "2026-11-05"}
]
```
قيم `tool`: `cv` `mukafaa` `mawzoona` `rateb` `khitab` `dareeba` `hub` `store`. الاسم والمدينة اختيارية.
